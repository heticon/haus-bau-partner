UM HAUS&BAU — DESIGN SYSTEM (consolidated)

Reference style: alka-bau.de / hid-friedrich.de structure and composition — translated into UM Haus&Bau's own palette. No orange/maroon accents anywhere; navy replaces them throughout.

1. Color system

Palette must come directly from the UM Haus&Bau logo — only 4 core colors: Primary Dark Blue (from logo), Gray (from logo), White, Black/Near Black

Dark Blue = primary accent · White = main background · Gray = secondary/supporting · Black/Near Black = strong typography

For dark sections (hero, Leistungen), use a lighter tint of navy (~#5C7FB0) for accent text/numbers so it stays legible against near-black backgrounds — same hue family, adjusted for contrast, not a new color

Do NOT use: green, orange, purple, bright red, neon, random accents, colorful/excessive gradients, glassmorphism. Gradients only if extremely subtle and within the palette.

Feel: calm, sophisticated, architectural, professional — not colorful or playful

⚠️ Blocked on: actual logo file to extract exact hex values (current mockups use #1B2A44 navy / #0B131F navy-deep as placeholders)

2. Typography — two-typeface system (confirmed via mockups)

Primary: modern high-quality sans-serif, bold weight for headlines (600–800), regular/medium for body (400–500). Exact typeface still open — pending visual references — but character is locked: modern, premium, architectural, precise, highly readable, confident. Avoid generic system fonts, futuristic/playful/decorative fonts, SaaS-startup feel.

Secondary (accent) typeface — monospace: used specifically for eyebrow tags (— [ 03 — LEISTUNGEN ]), section numbers (01, 02...), and small tracked labels/stats. This is a deliberate second typeface, not just a style variant of the primary font.

Italic accent: headline emphasis words (e.g. "Ein Ansprechpartner") use a serif italic (Georgia-style), distinct from both the bold sans and the monospace — a third, very sparingly-used voice reserved for emotional/emphasis moments in headlines only.

Weights: Regular 400 / Medium 500 / Semibold 600 / Bold 700. Headlines generally 600–700 (or 800 for hero-level), body 400–500, buttons/UI 500–600. Avoid too many weights in use at once.

Scale (guideline, not rigid)

Letter spacing: large headlines neutral/slightly negative · body neutral · small/uppercase/mono labels slightly increased tracking. Don't overuse uppercase.

3. Spacing system

Base scale (multiples of ~4–8px): 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 120 / 160

Container max-width: 1200–1320px, centered, don't stretch on huge screens

Section spacing — desktop: 96–160px · mobile: 64–96px

Cards: consistent gaps/padding/ratios, subtle borders, minimal rounding (~4–12px), avoid cramped feeling

Whitespace is a deliberate design element — don't fill it with extra text/cards/icons/stats/animation just to fill space

4. Signature layout patterns (confirmed via reference + mockup review)

Eyebrow tag: short horizontal dash + monospace uppercase label, optionally bracketed with a section number: — [ 01 — Philosophie ]

Hero: dark navy gradient background (photo-based once real photography exists), eyebrow → bold headline with one italic-accent phrase → short subline → pill-shaped primary (filled white) + secondary (ghost/outlined) CTA buttons

Stats bar: sits as a semi-transparent overlay directly on the bottom of the hero image/background (not a separate flat section below it) — 4 stats, thin vertical dividers, mono numbers + small uppercase mono labels

Light sections (e.g. philosophy/manifest, projects): off-white/cream background (not pure white) with a very subtle dot-grid texture, not flat white

Dark sections (e.g. Leistungen): near-black background with a soft radial glow (navy-tinted, low opacity) in one corner for depth

Cards on dark backgrounds: no fill beyond a slightly-lighter-than-background panel, thin 1px border, mono number top, bold heading, gray description; one "active/featured" card gets a colored border ring + small arrow icon to show interactive state

Buttons: fully rounded (pill-shape), not sharp rectangles

Project cards: category eyebrow (mono) + bold project name over a photo with dark gradient overlay at the bottom for legibility; featured items get a small pill badge

5. Core brand feeling

Should feel like a high-quality, reliable, professional German construction company with strong craftsmanship and architectural awareness — quality shown through clarity, precision, structure and detail, not luxury or visual effects

Target first-impression reaction: "Diese Firma wirkt professionell, zuverlässig und kompetent. Mein Projekt ist hier in guten Händen."

Desired qualities: Professional · Reliable · Precise · High-quality · Modern · Clean · Structured · Experienced · Trustworthy · Approachable · German · Craftsmanship-focused · Architectural · Established

Premium, not luxury — quality comes from typography, photography, spacing, alignment, clean layouts, restrained colors, hierarchy, authentic projects, polished interactions, attention to detail. NOT from expensive-looking effects, black-and-gold styling, extravagant animation, overly artistic/complex layouts.

Brand personality: confident not arrogant · professional not corporate · modern not futuristic · high-quality not luxurious · precise not cold · personal not casual · established not old-fashioned · approachable not cheap

Visual direction: "Modern German craftsmanship + architectural precision + reliable project management" — closer to a well-established German construction company with excellent branding than a luxury architecture studio or generic Handwerker site

6. Avoid

Generic SaaS design · startup aesthetics · luxury-brand aesthetics · black-and-gold · excessive rounded cards/gradients/glassmorphism · cartoon illustrations · fake stock photography · excessive icons/animations · futuristic or overly experimental UI · template-looking sections · cheap construction clichés · AI-generated visual clichés

Core principle

Quality should be visible through precision, not decoration. "Gute Arbeit. Klare Kommunikation. Zuverlässige Umsetzung."
